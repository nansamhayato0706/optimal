# 目的

- 文字化け（CP932 混入など）と UTF-8 BOM 混入を防ぐ
- 既存の改行コード（LF/CRLF）を維持する

# 必須ルール

- 保存は **UTF-8 (BOM なし)** 固定
- 既存の改行コードを維持（勝手に統一しない）
- 日本語を含む変更は表示/出力確認を前提に扱う
- 文字化け疑い時は「直す」より **クリーンソースから再編集** を優先

# 出力/提案の型

- 変更は最小差分
- "ついで修正" は禁止（必要なら別提案として分離）
